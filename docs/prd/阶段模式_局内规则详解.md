# 阶段模式 — 局内规则与玩法描述

> 对应设计文档：肉鸽塔防_游戏设计定案.md V2.0
> 对应数值文档：肉鸽塔防_数值框架与MVP.md V2.1

---

## 1. 模式概述

**阶段模式**是游戏的核心模式，玩家选择一名英雄，挑战 4 个连续阶段，每个阶段 6 分钟，击杀每阶段末尾的 Boss，最终挑战最终 Boss。

```
一局总时长：约 25-35 分钟（含 Boss 战）
核心目标：在 4 个阶段中生存下来，击败最终 Boss
失败条件：炮塔 HP 归零
胜利条件：击败最终 Boss
```

---

## 2. 对局前准备

### 2.1 流程

```
主界面 → 选择模式(阶段模式) → 选择难度 → 选择英雄 → 确认出征 → 进入战斗
```

### 2.2 选择难度

```
玩家选择已解锁的难度（MVP 为难度 1-10，完整版 1-100）
难度影响：敌人属性、Boss 属性、掉落收益倍率
首次游玩：默认难度 1
```

### 2.3 选择英雄

```
选择已解锁的英雄（MVP：仲裁官 初始可用 / 弹幕大师 通关难度1解锁）
英雄选择后确认，不可在对局中更换。
```

### 2.4 局外加成生效

```
进入对局前，以下局外加成已自动生效：
  ✓ 全局天赋树（所有已升级天赋）
  ✓ 属性宝石（所有已获得宝石）
  ✓ 成就加成（所有已激活的成就加成）
  ✓ 称号效果（当前装备的称号）
```

## 3. 阶段结构

### 3.1 总览

```
一场阶段模式 = 4 个阶段

阶段 1 → 阶段 Boss(巨像) → 阶段 2 → 阶段 Boss(双生体) →
阶段 3 → 阶段 Boss(指挥官) → 阶段 4 → 阶段 Boss(虚空巨兽) →
最终 Boss(虚空之核) → 胜利结算
```

### 3.2 各阶段参数

| 参数 | 阶段 1 | 阶段 2 | 阶段 3 | 阶段 4 |
|------|--------|--------|--------|--------|
| 时长 | 6 min | 6 min | 6 min | 6 min |
| 刷新间隔 | 1.0s | 0.8s | 0.6s | 0.4s |
| 最大敌人数 | 30 | 45 | 60 | 80 |
| 阶段 Boss | 巨像 | 双生体 | 指挥官 | 虚空巨兽 |
| 敌人强度倍率 | ×1.0 | ×1.6 | ×2.4 | ×3.6 |

### 3.3 阶段间过渡

```
阶段过渡规则：
  1. 阶段 6 分钟倒计时结束 → 阶段 Boss 登场
  2. 阶段 Boss 出现后，立即开始 20 秒倒计时
  3. 20 秒内击杀 Boss → 获得掉落，常规敌人继续刷新
  4. 20 秒未击杀 → 自动进入下一阶段，Boss 不消失
  5. 没有阶段间隙（不暂停），战斗持续进行
  6. 玩家可随时手动暂停来整理背包、调整战术等
```

**Boss 跨阶段堆积效果：**

```
场景示例：
  阶段 1 Boss（巨像）未在 20 秒内击杀
  → 进入阶段 2，巨像仍在场上
  → 阶段 2 结束时，双生体 Boss 登场
  → 场上可能有：巨像 + 双生体 同时存在
  → 阶段 3、4 同理，最多 4 个阶段 Boss 同时在场
  → 策略提示：尽快击杀 Boss 避免堆积
```

## 4. 局内战斗规则

### 4.1 炮塔

```
炮塔位于屏幕中心偏下位置，是玩家的核心。
炮塔自动攻击，攻击逻辑由玩家勾选的策略决定。
玩家也可手动点击某个敌人进行集火。

炮塔属性：
  HP：初始值由英雄基础 + 局外加成决定
  攻击：由英雄专属武器 + 副武器 + 等级加成 + 局外加成决定
  防御：由英雄基础 + 局外加成决定
```

### 4.2 攻击方式

```
双模攻击系统：

【自动模式】
  炮塔按攻击逻辑面板的勾选策略自动选择目标并攻击。
  可多选策略，多选时取同时满足所有条件的敌人。
  默认策略：最近优先。

【手动集火】
  玩家点击战场上的任意敌人 → 炮塔锁定该目标
  集火期间暂停自动逻辑，目标死亡后恢复
  手动集火时有红色瞄准标记显示在目标上
```

### 4.3 攻击逻辑面板

```
玩家可随时打开战术面板，勾选/取消策略：
  ☑ 最近优先      ☐ 血量最低      ☐ 精英优先
  ☐ 治疗者优先    ☐ 召唤者优先    ☐ 锁定击杀
  ☐ 高威胁优先    ☐ 均衡攻击      ☐ Boss 优先

注：MVP 版本的敌人暂时没有"治疗者"和"召唤者"类型，
这两个选项保留但在它们出现前无效果。
```

### 4.4 敌人刷新机制

```
刷新规则：
  1. 敌人从屏幕四边生成，向炮塔移动
  2. 有最小刷新间隔（每阶段不同）
  3. 有最大同时存在敌人数（每阶段不同）
  4. 达到最大上限时暂停刷新
  5. 击杀敌人腾出空间后继续刷新
  6. 玩家可通过击杀守卫 Boss 缩短刷新间隔

各阶段刷新密度（难度 1）：
  阶段 1：每 1s 最多刷 1 只，场上最多 30 只
  阶段 2：每 0.8s 最多刷 1 只，场上最多 45 只
  阶段 3：每 0.6s 最多刷 1 只，场上最多 60 只
  阶段 4：每 0.4s 最多刷 1 只，场上最多 80 只
```

### 4.5 精英敌人

```
精英刷新：每个阶段内不定时刷新（随机间隔 15-45s）

精英特征：
  ✓ 比普通敌人大 30%，发光
  ✓ 带 1 个随机精英词缀（不同颜色标识）
  ✓ 血量 = 普通 × 3-5 倍
  ✓ 掉落更多经验和金币

精英词缀（MVP 5 种）：
  强壮(红) → HP+100%
  急速(黄) → 移速+60%
  护盾(蓝) → 每 10s 生盾
  爆炸(橙) → 死亡爆炸
  分裂(绿) → 死分 4 小兵
```

### 4.6 敌人难度缩放

```
难度 N 中敌人的实际属性：

敌人 HP      = 基础HP × 阶段倍率 × (1.10)^(N-1)
敌人伤害    = 基础伤害 × 阶段倍率 × (1.08)^(N-1)

例：难度 5，阶段 3 的小兵：
  HP = 40 × 2.4(阶段3) × 1.46(难度5) = 140
  伤害 = 5 × 2.0(阶段3) × 1.36(难度5) = 13.6
```

## 5. 三种召唤 Boss

### 5.1 召唤规则

```
玩家可随时召唤 Boss，无需等到敌人满上限。

召唤方式：
  点击底部「👾召唤」按钮 → 弹出 3 个 Boss 选项
  点击选择要召唤的 Boss → Boss 立即登场

Boss 存活时间：召唤后存在有限时间，超时未击杀则自动消失（无掉落）

策略意义：
  守卫 Boss → 加速发育（推荐尽早召）
  金币 Boss → 缺金币抽卡时召
  击杀数 Boss → 想买大件时召
```

### 5.2 守卫 Boss

```
冷却：无冷却
最多生效：2 次（第 3 次起击杀无间隔收益）
效果：击杀后刷新最小间隔 -1s（最低 0.2s）
存活时间：30 秒

建议：进入新阶段后尽快召唤 2 次，将刷新间隔压到最低
```

### 5.3 金币 Boss

```
冷却：90 秒
效果：击杀掉落大量金币（≈ 普通击杀 × 10）
存活时间：30 秒
```

### 5.4 击杀数 Boss

```
冷却：90 秒
效果：击杀掉落大量击杀数（≈ 50-80）
存活时间：30 秒
```

## 6. 局内成长系统

### 6.1 等级系统

```
击杀敌人 → 获得经验 → 经验满自动升级

升级效果（自动生效）：
  每升 1 级：基础攻击 +3%，基础血量 +2%

专武升级节点（手动/自动触发重要变化）：
  Lv.5  → 专有武器第一次进化
  Lv.10 → 专有武器第二次进化
  Lv.15 → 专有武器第三次进化
  Lv.20 → 专有武器最终进化
```

**典型等级节奏（难度 1）：**

| 阶段结束时 | 预期等级 | 关键节点 |
|-----------|---------|---------|
| 阶段 1 | Lv.6-7 | 已获得 Lv.5 专武进化 |
| 阶段 2 | Lv.10-11 | 已获得 Lv.10 专武进化 |
| 阶段 3 | Lv.14-15 | 即将/已获得 Lv.15 专武进化 |
| 阶段 4 | Lv.19-20 | 可能获得 Lv.20 最终进化 |

### 6.2 金币 — 肉鸽抽卡

```
杀敌获得金币 → 点击右上角金币图标 → 打开抽卡界面
每次消耗 200 金币，从 3 个随机技能/属性中选择 1 个
费用每次 +50（200→250→300...），不限次数

抽卡可获得的强化（MVP 版本 10 种）：
  普通级：暴击+5%、攻速+10%、血量上限+20%、金币+25%、经验+20%
  稀有级：火焰附加、冰冻附加、吸血、Boss 伤害+25%
  史诗级：子弹穿透+1、击杀爆炸、武器伤害+20%
```

### 6.3 击杀数 — 击杀商店

```
杀敌获得击杀数（每只 +1）→ 点击右上角击杀数图标 → 打开商店
击杀数跨阶段保留

商品列表（每阶段限购 1 次）：
  攻击强化：200击杀 → 伤害+15%（本阶段）
  防御强化：150击杀 → 减伤+10%（本阶段）
  攻速强化：250击杀 → 攻速+20%（本阶段）
  暴击强化：300击杀 → 暴击率+8%（本阶段）
  生命恢复：100击杀 → 立即回 20% 血量
  临时护盾：100击杀 → 获得 2 层护盾
```

### 6.4 三种资源的关系

```
经验（自动） → 等级 → 基础属性 + 专武进化
  玩家不需要做选择，稳定变强

金币（主动） → 抽卡 → 技能/属性强化
  玩家需要决策：抽什么？什么时候抽？

击杀数（主动） → 商店 → 阶段 Buff
  玩家需要决策：攒着买大的？还是花在小的上？
```

## 7. 武器系统局内规则

### 7.1 武器栏位

```
玩家拥有 4 个武器栏位：
  Slot 1：英雄专属武器（永久锁定，不可替换）
  Slot 2：可锁定/解锁（默认未锁定）
  Slot 3：可锁定/解锁（默认未锁定）
  Slot 4：可锁定/解锁（默认未锁定）

锁定状态含义：
  锁定(🔒) → 该栏位武器不会被替换
  未锁定(🔓) → 获得新武器时该栏位可被替换
```

> **实现状态（2026-09）**：这一节已在 HUD 落地 —— `View_Game_Stage.prefab` 的 `skills` 节点下已有 **4 个槽位**，槽 0（索引 0）= 英雄专属技能、**永久锁定不可解锁**（`HERO_SLOT_UNLOCKABLE = false`，想放开就改这一行），槽 1~3 可锁定/解锁（点锁图标切换）。
> 落槽口径：新技能**已拥有 → 原地升 1 级**（`max_level` 封顶）；否则**优先填「索引最小的未锁定空槽」**，未锁定槽都满了才**替换索引最小的未锁定槽**（被顶掉的技能重新回到抽取池）；
> 一个未锁定槽都没有 → 发放失败、UI 飘字提示。英雄自带技能按顺序占最低的几个索引，所以槽 0 天然就是"专属武器"（**设计稿说的是"武器"，实现的是"技能"**，槽位语义一一对应）。
> 代码：`assets/scripts/game/battle/SkillSlots.ts`（纯规则）+ `assets/scripts/game/ui/scenes/scene_game_stage/cmps/skill_slot/SkillSlot.ts`（格子组件：图标/等级/CD/锁）；
> 规则体检 `npm run audit:slot`。

### 7.2 武器获取

```
副武器只能通过局内掉落获得：
  精英掉落：40% 概率掉落 1 件（白~紫品质）
  阶段 Boss：必定掉落 2 件（至少稀有）
  最终 Boss：必定掉落 3 件高品
  金币 Boss：概率掉落
  击杀数 Boss：概率掉落
```

### 7.3 武器替换流程

```
获得武器 → 进入临时背包

替换方式（背包内操作）：
  方式 A（快速）：双击武器 → 自动替换第一个未锁定栏位
  方式 B（精确）：拖动武器到指定栏位 → 替换该栏位

替换后：旧武器消失（当前版本不返还资源）
```

### 7.4 武器升星

```
获得同名武器 → 自动升星：
  ☆1 → ☆2：基础属性 +40%
  ☆2 → ☆3：基础属性 +40%（累乘 ×1.96）+ 解锁额外词缀效果

例：获得第 2 把速射炮 → 升为 ☆2；获得第 3 把 → 升为 ☆3
```

### 7.5 品质与词缀

```
品质决定了武器的基础属性和词缀数量：
  普通(白) ×1.0：无词缀
  稀有(蓝) ×1.3：1 条随机词缀
  史诗(紫) ×1.6：2 条随机词缀
  传说(橙) ×2.0：3 条随机词缀 + 特殊效果
  独特(红) ×2.5：固定独特效果 + 3 词缀

词缀示例：
  +15% 伤害    +15% 攻速    击杀回 2% 血
  忽视 20% 防  状态延长 30%  攻击范围 +20%
  精英伤 +25%  暴击率 +8%   暴击伤害 +25%
```

## 8. 临时背包与道具

```
容量：默认 8 格（天赋可扩展）
```

## 9. 阶段 Boss 战规则

### 9.1 Boss 登场

```
每个阶段 6 分钟倒计时结束时：
  1. 阶段 Boss 从屏幕外登场
  2. Boss 血条出现在屏幕顶部（粗血条 + Boss 名称）
  3. 20 秒倒计时开始（血条旁边显示）
  4. 常规敌人继续刷新
```

### 9.2 20 秒倒计时

```
20 秒内击杀 Boss：
  ✓ Boss 爆炸，掉落奖励（2 副武器 + 2 道具）
  ✓ 清理掉 Boss 的压力
  ✓ 常规战斗继续

20 秒未击杀 Boss：
  ✓ 倒计时结束时自动进入下一阶段
  ✓ Boss 不消失，继续在场
  ✓ 下一阶段的常规敌人和精英继续刷新
  ✓ 下一阶段的 Boss 会在 6 分钟后正常登场
  ✓ 叠 Boss 越多，压力越大
```

### 9.3 各阶段 Boss 特性

| 阶段 | Boss | HP(难度1) | 关键机制 | 打法提示 |
|------|------|-----------|---------|---------|
| 1 | 巨像 | 2,000 | 冲击波推开武器；50%血狂暴 | 注意小怪堆积 |
| 2 | 双生体 | 1,500×2 | 距离越近减伤越高；8s换位 | 攻击逻辑勾选"Boss优先" |
| 3 | 指挥官 | 3,000 | 6s召唤小兵；友军伤害+30%光环 | 尽快击杀本体 |
| 4 | 虚空巨兽 | 4,000 | 5s瞬移；弹幕；30%血狂暴 | 范围武器+持续伤害 |

### 9.4 Boss 跨阶段堆积示例

```
假设玩家打得比较慢：

  第 6:00 → 巨像登场，未在 20s 内击杀
  第 7:00 → 进入阶段 2，巨像仍在
  第 12:00 → 双生体登场
  第 12:20 → 20s 到，巨像+双生体都活着
  第 13:00 → 进入阶段 3，2 个 Boss 在场
  第 18:00 → 指挥官登场... 3 个 Boss
  第 24:00 → 虚空巨兽登场... 4 个 Boss + 最终 Boss

建议：尽量在 20 秒内击杀阶段 Boss，避免堆积。
```

## 10. 最终 Boss 战

### 10.1 触发条件

```
阶段 4 Boss（虚空巨兽）被击杀后，最终 Boss 立即登场。
如果虚空巨兽在 20 秒内被击杀 → 最终 Boss 在阶段 4 末尾登场。
如果虚空巨兽存活进入下一阶段 → 无下一阶段，继续战斗直到击杀
（注：阶段 4 是最后一个阶段，击杀虚空巨兽后才会出最终 Boss）
```

### 10.2 最终 Boss 属性

```
虚空之核（难度 1）：
  HP：6,000
  伤害：40
  机制：综合所有 Boss 特性，多阶段战斗

  阶段 1（HP 100%-60%）：常规攻击 + 弹幕
  阶段 2（HP 60%-30%）：增加召唤小兵 + 瞬移
  阶段 3（HP 30%-0%）：全屏技能 + 狂暴模式
```

### 10.3 最终 Boss 掉落

## 11. 死亡与结算

### 11.1 死亡机制

```
炮塔 HP 归零 → 本局结束

死亡时可以：
  ✓ 看激励视频广告 → 满血复活，继续当前对局
  ✗ 放弃 → 进入结算界面

复活次数上限：每日 3 次（激励视频）
```

### 11.2 结算奖励

```
对局结束时（无论胜利/失败）进入结算界面：

通关结算公式（难度 1）：
  通用金币 = 50 + 阶段数×30 + 难度系数×50 + 击杀数×0.5
  属性宝石 = 2~3 颗随机宝石（基础）

  例：通关 4 阶段，击杀 1,800 只
  通用金币 = 50 + 4×30 + 1.0×50 + 1800×0.5 = 1,120
  属性宝石 = 2 颗

失败结算公式：
  通用金币 = 10 + 完成阶段数×15 + 击杀数×0.3
  属性宝石 = 1 颗

结算时可通过看广告翻倍（每日 5 次）。
```

### 11.3 成就进度

```
对局中的击杀、精英击杀、Boss 击杀、通关等
全部会计入成就进度，在结算时更新。
```
