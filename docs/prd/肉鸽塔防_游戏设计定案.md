## 1. 核心玩法总览

### 一句话定义

> 玩家固定在屏幕中央，炮塔**默认自动攻击**（可手动点击集火），通过 4 阶段生存挑战打造武器组合，击杀精英和 Boss 获取武器与道具，构建强力 Build。

### 核心循环

```
进入对局 → 选英雄+难度 → 阶段 1（6分钟）+ 阶段 Boss →
阶段 2（6分钟）+ 阶段 Boss → 阶段 3（6分钟）+ 阶段 Boss →
阶段 4（6分钟）+ 阶段 Boss → 最终 Boss → 结算
```

### 玩家操作内容

| 操作 | 频率 | 说明 |
|------|------|------|
| **手动点击攻击** | 随时 | 点击怪物临时集火，覆盖自动逻辑 |
| **攻击逻辑勾选** | 动态调整 | 9 种优先级策略可多选 |
| **升级选择** | 每升 1 级 | 自动提升基础属性 + 专武节点 |
| **金币抽卡** | 随时消耗 | 从技能/属性池抽 3 选 1 |
| **击杀商店** | 随时消耗 | 用击杀数购买阶段 Buff |
| **临时背包管理** | 随时（可暂停） | 使用道具、替换武器 |
| **召唤 Boss** | 随时 | 守卫/金币/击杀数三种 Boss |
| **暂停整理** | 任意时刻 | 暂停游戏操作背包/商店/逻辑 |

## 2. 阶段系统

### 2.1 基本结构

```
一局阶段模式 = 4 个大阶段
每个大阶段 = 6 分钟连续战斗
阶段之间 → 无间隔（Boss 存活时继续下一阶段）
玩家可随时暂停 → 操作背包/商店/攻击逻辑
```

### 2.2 阶段内逻辑

```
阶段开始
  │
  ├── 持续刷新敌人（最小间隔、最大上限）
  ├── 不定时刷新精英敌人
  ├── 三种召唤 Boss 供玩家随时召唤
  │
  ├── 6分钟结束 → 阶段 Boss 登场（叠加在常规敌人之上）
  │     ├── 20 秒内击杀 → 正常掉落 + 减负
  │     └── 20 秒未击杀 → 进入下一阶段，Boss 仍然存在场上
  │
  └── 阶段 4 Boss 击杀后 → 最终 Boss 登场
```

### 2.3 核心规则：Boss 跨阶段存活

```
- 阶段 Boss 出现后，20 秒内未击杀则自动进入下一阶段
- Boss 不消失，继续在场上一同战斗
- 后续阶段 Boss 也会在 6 分钟时正常登场
- 可能同时存在多个未击杀的阶段 Boss
- 这意味着拖延越久，场上 Boss 越多，压力越大
- 【策略】尽快击杀阶段 Boss，避免 Boss 堆积
```

### 2.4 敌人刷新参数

| 阶段 | 最小间隔(s) | 最大敌人数 | Boss 登场 |
|------|------------|-----------|-----------|
| 阶段 1 | 1.0 | 30 | 6min 时 |
| 阶段 2 | 0.8 | 45 | 12min 时 |
| 阶段 3 | 0.6 | 60 | 18min 时 |
| 阶段 4 | 0.4 | 80 | 24min 时 |
| 阶段 4→最终 | — | — | 阶段4 Boss击杀后 |

## 3. 攻击系统（自动+手动点击）

### 3.1 双模攻击

```
默认模式：自动攻击
  炮塔按照"攻击逻辑面板"的勾选策略自动选择目标

手动模式：点击攻击（覆盖自动逻辑）
  玩家点击某个敌人 → 炮塔立即集火该目标
  集火持续到该目标死亡，然后恢复自动逻辑
  手动点击覆盖自动策略，但不改变勾选状态
```

### 3.2 攻击逻辑面板

玩家可随时（含暂停时）勾选/取消勾选以下选项（可多选）：

| 选项 | 效果 | 默认 | 说明 |
|------|------|------|------|
| **最近优先** | 优先攻击最近敌人 | ✔ | 基础保底逻辑 |
| **血量最低** | 优先攻击血量%最低 | ✘ | 快速减员 |
| **精英优先** | 优先攻击精英怪 | ✘ | 防止精英堆积 |
| **治疗者优先** | 优先攻击治疗单位 | ✘ | 打断敌方续航 |
| **召唤者优先** | 优先攻击召唤单位 | ✘ | 防止滚雪球 |
| **锁定击杀** | 锁定目标直至击杀才切换 | ✘ | 避免火力分散 |
| **高威胁优先** | 优先攻击伤害最高/自爆单位 | ✘ | 生存向策略 |
| **均衡攻击** | 均匀攻击所有敌人，不集火 | ✘ | 雨露均沾 |
| **Boss 优先** | Boss 在场时优先 Boss | ✘ | 快速结束 Boss 战 |

### 3.3 优先级运算法则

```
1. 多选时：先筛选同时满足所有勾选条件的敌人
2. 筛选结果中按面板顺序（上→下）决定最终目标
3. 手动点击集火时→暂停自动逻辑，目标死亡后恢复
4. 无任何勾选时→默认"最近优先"
5. "锁定击杀"特殊：锁定后不切换目标，被锁目标死亡后才重新选择
```

## 4. 战斗与属性系统

### 4.1 战斗公式

```
每秒伤害 (DPS) = 武器基础伤害 × 攻击速度 × (1 + 所有增伤百分比)
暴击伤害 = 伤害 × (1 + 暴击伤害加成)

实际攻击 = DPS × 英雄系数 × 等级加成 × 局外宝石加成

炮塔承伤 = 敌人攻击力 × (1 - 减伤%)
减伤% = 防御值 / (防御值 + 100)
```

### 4.2 属性系统

| 属性 | 状态效果 | 叠加规则 |
|------|---------|---------|
| **物理** | 无特殊，纯粹伤害 | 线性 |
| **火焰** | 燃烧：每秒 15% 武器伤害，持续 3s | 刷新时间，叠 3 层 |
| **冰冻** | 减速 20%，叠 3 层冻结 1.5s | 冻结后重置 |
| **雷电** | 弹射 2 个目标（50% 伤害） | 增加弹射次数/范围 |
| **毒液** | 持续伤害 10%/s，5s + 减治疗 30% | 叠层加秒伤，上限 5 层 |
| **爆炸** | 范围 60% 伤害（2m 内） | 增加半径和伤害% |
| **暗影** | 对 <30% 血敌人额外 50% 伤害 | 提高斩杀阈值 |

### 4.3 防御系统

```
炮塔血量 = 基础 × (1 + 英雄加成 + 局外宝石加成) + 局内升级加成
护盾 = 额外伤害吸收层（道具/技能获得）
减伤 = 防御 / (防御 + 100)
```

## 5. 英雄/角色系统

### 5.1 英雄框架

每个英雄拥有：
1. **专属武器**（Slot 1，永远锁定，不可替换）
2. **英雄特性**（被动效果）
3. **局内专武升级**（Lv.5/10/15/20 自动触发）

### 5.2 英雄设计

#### 英雄 1：仲裁官（初始可用）

```
专属武器：审判之光 — 持续激光束，自动追踪
特性：对 >50% 血敌人 +20% 伤害
专武进化：
  Lv.5  → 叠伤害层数上限 10→15 层
  Lv.10 → 切换目标保留 50% 层数
  Lv.15 → 满层时额外 3% 最大生命伤害
  Lv.20 → 光束宽度 +50%，同时攻击 2 目标
```

#### 英雄 2：弹幕大师（需解锁）

```
专属武器：弹幕阵列 — 扇形 5 发散射
特性：攻击范围 +25%，远程伤害 +15%
专武进化：
  Lv.5  → 弹丸 +2
  Lv.10 → 弹丸速度 +40%
  Lv.15 → 击中后分裂为 2 小弹丸
  Lv.20 → 全方位 360° 发射
```

#### 英雄 3：守护者（需解锁）

```
专属武器：防御矩阵 — 环绕炮塔的防御球，自动攻击
特性：炮塔血量 +50%，每个防御球减伤 5%
专武进化：
  Lv.5  → 旋转速度 +30%
  Lv.10 → 防御球 +1（上限 5）
  Lv.15 → 击中回复 1% 血量
  Lv.20 → 可拦截敌方子弹
```

#### 英雄 4：元素使（需解锁）

```
专属武器：元素法球 — 火→冰→雷→毒循环
特性：每有一种不同属性副武器，全属性伤害 +8%
专武进化：
  Lv.5  → 周期 5s→4s
  Lv.10 → 切换时触发小范围元素爆发
  Lv.15 → 同时附加当前+上一属性
  Lv.20 → 法球 +2 枚轮流切换
```

### 5.3 副武器与英雄特性联动

```
部分副武器可与英雄特性产生协同效应：

仲裁官 + 激光切割器 → 激光切割器享受"对高血量敌人增伤"加成
弹幕大师 + 散射炮/迫击炮 → 弹幕数量叠加，"火力覆盖"范围加成
守护者 + 电磁场/链锯刃 → 近距离武器受益于减伤光环
元素使 + 任何属性武器 → "元素共鸣"直接加成对应属性

目的：让特定英雄对特定副武器有"隐性偏好"，但不是强制绑定
```

### 5.4 英雄解锁

| 英雄 | 通用金币解锁 | 或 | 成就解锁 |
|------|-------------|----|---------|
| 仲裁官 | 初始 | — | — |
| 弹幕大师 | 5000 | 或 | 通关阶段模式难度 2 |
| 守护者 | 8000 | 或 | 累计击杀 5000 |
| 元素使 | 12000 | 或 | 3 英雄通关阶段模式 |

## 6. 武器系统（4 栏位）

### 6.1 栏位结构

```
[Slot 1] ← 英雄专属武器 ── 永久锁定，不可替换
[Slot 2] ← 可锁定/解锁  ── 默认：未锁定
[Slot 3] ← 可锁定/解锁  ── 默认：未锁定
[Slot 4] ← 可锁定/解锁  ── 默认：未锁定

锁定 = 该栏位不会被替换
未锁定 = 获得新武器时可变
```

### 6.2 武器获取（仅局内）

```
除英雄专属武器外，所有副武器仅能在局内通过以下方式获得：

精英掉落  → 概率掉落 1 件（品质随机）
阶段 Boss → 必定掉落 2 件（至少稀有）
最终 Boss → 必定掉落 3 件高品
召唤 Boss → 金币Boss 概率掉 / 击杀数Boss 概率掉

所有副武器完全随机，局外无法购买或解锁指定武器。
```

### 6.3 替换流程

```
1. 武器掉入临时背包
2. 玩家打开背包（可暂停操作）
3. 替换方式：
   a. 双击背包武器 → 自动替换第一个未锁定栏位
   b. 拖动到指定栏位
4. 旧武器消失（或分解，待定）
```

### 6.4 武器升星

```
每个副武器最高 ☆3
获得同名武器自动升级：
  ☆1 → ☆2：基础属性 +40%
  ☆2 → ☆3：基础属性 +40% + 解锁额外词缀效果

例：获得 3 把速射炮 → 合为 ☆3 速射炮
```

### 6.5 品质系统

| 品质 | 颜色 | 属性倍率 | 额外 | 来源 |

| **普通** | 白 | ×1.0 | 无 | 常见 |

## 9. 局内商店与成长

### 9.1 金币 — 肉鸽抽卡

```
消耗金币 → 从技能/属性池抽 3 个选项 → 选择 1 个
费用递增：100/150/200/250... 每次消耗重置或继续递增（待定）
```

**可抽取的强化：**

| 类别 | 示例 | 权重 |
|------|------|------|
| **被动属性** | 暴击率+5%、攻速+10% | 常见 |
| **属性附加** | 武器附加火焰/雷电等 | 中等 |
| **生存强化** | 血量上限+20%、受伤无敌 1s | 中等 |
| **经济强化** | 金币+25%、经验+20% | 常见 |
| **主动技能** | 全屏冰冻、空袭召唤 | 低概率 |
| **特殊能力** | 击杀爆炸、子弹穿透+1 | 低概率 |

### 9.2 击杀数 — 击杀商店

```
击杀数全局保留（跨阶段不重置）
固定商品列表
每阶段结束自动刷新
也可消耗金币手动刷新
```

## 10. 三种召唤 Boss 机制

### 10.1 总览

| Boss 类型 | 召唤条件 | 冷却 | 作用 | 存活时间 |
|-----------|---------|------|------|---------|
| **守卫 Boss** | 随时 | **无冷却** | 击杀后刷新间隔 -1s（最低 0.2s） | 有限时间 |
| **金币 Boss** | 随时 | 有冷却 | 击杀掉落大量金币 | 有限时间 |
| **击杀数 Boss** | 随时 | 有冷却 | 击杀掉落大量击杀数 | 有限时间 |

### 10.2 守卫 Boss（刷新提速）

```
召唤条件：任何时刻均可
冷却：无
最多生效：2 次（最多减 2s 间隔）
每次击杀：刷新最小间隔 -1s
最低间隔下限：0.2s

策略：
  - 尽早召唤尽早受益
  - 2 次拉满后刷新达到最快
  - 更快的刷新 = 更多敌人 = 更多经验/金币/击杀数
```

### 10.3 金币 Boss

```
召唤条件：任何时刻均可
冷却：有（具体时长待定）
击杀掉落：大量金币
存活时间：到时间自动消失

策略：
  - 缺金币抽卡时召唤
  - 配合"金币磁铁"道具使用效果更佳
```

### 10.4 击杀数 Boss

```
召唤条件：任何时刻均可
冷却：有（独立于金币 Boss）
击杀掉落：大量击杀数
存活时间：到时间自动消失

策略：
  - 想买击杀商店大件时召唤
  - 击杀数跨阶段保留，前期攒后期花
```

### 10.5 Boss 存活时间

```
所有召唤 Boss 均有存活时间上限
到时间未击杀 → Boss 自动消失，无掉落
玩家需要在存活时间内集中火力击杀
存活时间受阶段/难度影响（越往后存活越短，或越长？待定）
```

## 13. 100 级难度系统

### 13.1 难度等级结构

```
100 个难度等级 = 10 个段位 × 每段位 10 级

段位名称（从低到高）：
  第 1 段：黑铁  I~X    (难度 1~10)
  第 2 段：青铜  I~X    (难度 11~20)
  第 3 段：白银  I~X    (难度 21~30)
  第 4 段：黄金  I~X    (难度 31~40)
  第 5 段：铂金  I~X    (难度 41~50)
  第 6 段：钻石  I~X    (难度 51~60)
  第 7 段：大师  I~X    (难度 61~70)
  第 8 段：宗师  I~X    (难度 71~80)
  第 9 段：传说  I~X    (难度 81~90)
  第 10 段：神话 I~X    (难度 91~100)
```

### 13.2 难度缩放公式

```
难度 N（N=1~100）的缩放系数：

敌人 HP      = 基础 × (1.10)^(N-1)
敌人伤害    = 基础 × (1.08)^(N-1)
刷新间隔    = 基础 × (0.98)^(N-1)
最大敌人数  = 基础 + (N-1) × 1
掉落收益    = 基础 × (1.03)^(N-1)
经验/金币   = 基础 × (1.05)^(N-1)
```

**关键节点缩放倍率：**

| 难度 | HP | 伤害 | 收益倍率 | 段位 |
|------|-----|------|---------|------|
| 1 | ×1.0 | ×1.0 | ×1.0 | 黑铁 I |
| 10 | ×2.4 | ×1.9 | ×1.5 | 黑铁 X |
| 20 | ×6.1 | ×4.0 | ×2.5 | 青铜 X |
| 30 | ×15.9 | ×8.7 | ×4.0 | 白银 X |
| 40 | ×41.1 | ×18.9 | ×6.5 | 黄金 X |
| 50 | ×106.7 | ×41.0 | ×10.6 | 铂金 X |
| 60 | ×277.0 | ×89.1 | ×17.2 | 钻石 X |
| 70 | ×718.7 | ×193.5 | ×28.0 | 大师 X |
| 80 | ×1864.9 | ×420.3 | ×45.6 | 宗师 X |
| 90 | ×4839.3 | ×912.8 | ×74.2 | 传说 X |
| 100 | ×12565.8 | ×1983.0 | ×120.8 | 神话 X |

### 13.3 段位进阶奖励

```
每突破一个新段位（难度 10/20/30...100）解锁特殊奖励：

突破 黑铁（难度10）→ 解锁第 2 个英雄栏位
突破 青铜（难度20）→ 解锁 Boss Rush 模式
突破 白银（难度30）→ 解锁第 3 个英雄选择
突破 黄金（难度40）→ 解锁第 2 套天赋页
突破 铂金（难度50）→ 解锁第 4 个英雄
突破 钻石（难度60）→ 解锁称号系统第 2 格
突破 大师（难度70）→ 解锁"独特"品质武器
突破 宗师（难度80）→ 解锁第 3 个天赋页
突破 传说（难度90）→ 解锁英雄异色皮肤
突破 神话（难度100）→ 解锁全游戏最强称号"神话"
```

### 13.4 难度解锁条件

```
难度 1：初始解锁
难度 2-100：通关前一级难度即可解锁
（如：通关难度 1 → 解锁难度 2，通关难度 2 → 解锁难度 3，以此类推）

不需要每个难度都完美通关，只需在任意模式下过关即可。
```

## 14. 游戏模式

### 14.1 模式总览

| 模式 | 说明 | 解锁 |
|------|------|------|
| **阶段模式** | 4 阶段 + 最终 Boss，标准体验 | 初始 |
| **无尽模式** | 在已解锁难度上无限阶段 | 通关阶段模式难度1 |
| **连战 Boss** | 以当前成长英雄连续挑战 Boss | 通关阶段模式难度2 |
| **每日挑战** | 固定种子，纯本地 | 通关阶段模式难度2 |

### 14.2 阶段模式

```
4 大阶段 + 阶段 Boss + 最终 Boss
可选手难度 1-100
通关解锁下一难度
推荐：标准体验、挑战新难度
```

### 14.3 无尽模式

```
在已解锁的难度基础上，进行无限阶段：

选择难度：玩家可选已解锁的任何难度（如已解锁到难度 40，可选 1-40）
阶段规则：每个阶段 6 分钟，无限延续
敌人成长：每个阶段敌人属性按系数增长
  HP × 1.25 / 阶段
  伤害 × 1.15 / 阶段
  刷新间隔 × 0.95 / 阶段
Boss：每隔 3 个阶段刷新一个 Boss
记录：最高到达阶段数
适合：测试 Build 上限、刷资源
```

### 14.4 连战 Boss 模式

```
玩家以自身当前局外成长（天赋+宝石+称号）进入挑战。

规则：
  1. 连续挑战 Boss，每个 Boss 击杀后短暂整备
  2. Boss 死亡掉落：副武器、金币、道具
  3. 整备期间可：
     - 打开背包替换/使用道具
     - 打开商店消费金币和击杀数
     - 调整攻击逻辑
  4. 无常规敌人阶段，纯 Boss 战
  5. 直到角色死亡或超时结束
  6. 记录：击败 Boss 数量

特点：
  - 局外成长直接影响上限
  - 考验单体爆发 Build
  - 快节奏，适合碎片时间
```

### 14.5 每日挑战

```
- 所有玩家相同配置（固定英雄、固定种子）
- 纯本地，无需联网
- 可能有特殊规则（如：只能用物理武器 / 敌人移速翻倍）
- 每日刷新
- 个人记录对比
```

## 17. 广告变现设计

### 17.1 广告类型

| 类型 | 机制 | 说明 |
|------|------|------|
| **激励视频** | 玩家主动观看 | 获得奖励 |
| **插屏广告** | 特定节点弹出 | 如阶段切换/结算回主界面 |
| **闲置弹广** | 长期不操作时弹出 | 检测玩家无操作 N 秒后 |

### 17.2 激励视频点位

| 点位 | 奖励 | 日上限 |
|------|------|--------|
| **死亡复活** | 满血继续当前局 | 3 次 |
| **结算翻倍** | 通用金币×2 | 5 次 |
| **商店刷新** | 免费刷新击杀商店 | 10 次 |
| **免费抽卡** | 免费一次肉鸽抽卡 | 5 次 |
| **Boss 额外掉落** | 阶段 Boss 额外掉 1 件 | 3 次 |
| **开局增益** | 开局随机道具 | 3 次 |
| **背包扩容** | 本局背包+4 格 | 2 次 |

### 17.3 插屏广告点位

| 节点 | 说明 |
|------|------|
| **阶段切换时** | 每个大阶段过渡时（每日有频次上限） |
| **结算回主界面** | 从对局回到主界面时 |
| **英雄解锁时** | 仅显示一次，可跳过 |

### 17.4 闲置弹窗广告

```
检测玩家 N 秒（如 30 秒）无任何操作 → 弹出插屏广告
玩家点击屏幕/触摸后恢复 → 广告关闭
避免在 Boss 战/高压期间弹出（可设定检测条件：当前敌人数 < 10 时触发）
```

### 17.5 去广告购买

```
一次性购买：
  - 移除所有插屏广告
  - 激励视频变为"一键领取"
  - 每日激励上限翻倍
  - 移除闲置弹窗广告
```

## 18. 美术风格建议

### 18.1 参考 Glyphica

```
暗色背景（深灰/黑色）
冷色系主色调（蓝灰、紫灰）
几何形状敌人（圆/三角/五边/菱形）
高可读性文字
克制粒子效果
干净 UI 布局
```

### 18.2 英雄配色

```
仲裁官：金/白（圣光）
弹幕大师：蓝/紫（科技）
守护者：绿/青（生命）
元素使：多色渐变（元素）
```

### 18.3 品质发光

```
普通：无  → 稀有：淡蓝微光 → 史诗：紫色光晕
传说：金色流光 → 独特：红色脉冲
```
