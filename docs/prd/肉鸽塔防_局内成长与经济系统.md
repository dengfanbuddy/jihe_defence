## 1. 局内等级系统（固定值）

> 每局重置，每升一级获得固定属性增长，与局外等级**独立计算**。

### 1.1 升级收益

| 收益 | 数值 | 说明 |
|------|------|------|
| **攻击力** | +2/级 | 固定值增长 |
| **生命值** | +10/级 | 固定值增长 |
| **专武进化检查** | Lv.10/20/30 | 达到时自动触发进化 |

### 1.2 经验曲线

```
升级所需经验 = 80 × (等级 + 1) × 1.15^等级

Lv.1 → 2:  80 × 2 × 1.15¹  = 184
Lv.9 → 10: 80 × 10 × 1.15⁹  = 2,815
Lv.19 → 20: 80 × 20 × 1.15¹⁹ = 9,506
Lv.29 → 30: 80 × 30 × 1.15²⁹ = 27,642
```

### 1.3 各阶段预估等级

| 阶段 | 时长 | 预估等级 | 关键节点 |
|------|------|---------|---------|
| 阶段 1 | 0-6min | Lv.1-12 | **Lv.10 专武第一次进化** |
| 阶段 2 | 6-12min | Lv.13-22 | **Lv.20 专武第二次进化** |
| 阶段 3 | 12-18min | Lv.23-32 | **Lv.30 专武第三次进化** |
| 阶段 4 | 18-24min | Lv.33+ | 持续成长 |

## 2. 幸运属性系统

### 2.1 幸运属性定义

| 属性 | 说明 | 初始值 | 上限 |
|------|------|--------|------|
| **幸运** | 影响抽取品质的概率 | 0 | 100（无硬上限，超过 100 部分效果折半） |

### 2.2 幸运的作用

```
每次抽取时，幸运值影响"跳阶"概率：

基础概率（当前阶段决定抽取阶位分布）
每 10 点幸运 = 将一次抽到的物品"升阶"概率 +5%

例：
  阶段 1：T1=80%, T2=18%, T3=2%
  幸运 20：T1→T2 的概率增加 10%（变为 T1=70%, T2=28%, T3=2%）
  幸运 50：T1→T2 的机率增加 25%（T1=55%, T2=43%, T3=2%）

幸运还影响：
  - 副武器掉落的初始星级（幸运 > 30 时，有概率直接获得 ☆2 武器）
  - 某些技能的额外效果触发概率
```

### 2.3 幸运的获取途径

| 途径 | 获得 | 说明 |
|------|------|------|
| **基础幸运** | 0 | 初始 |
| **击杀精英** | +1（本局有效） | 每次击杀精英 |
| **肉鸽技能：幸运星** | 永久 +5/10/15 | 可叠加 |
| **肉鸽技能：狗屎运** | +30（持续 3 次抽取） | 临时效果 |
| **通关阶段 Boss** | +3（本局有效） | 每阶段 Boss 击杀 |
| **副武器：幸运硬币** | 装备时 +10（持续） | 特殊副武器 |

## 3. 肉鸽抽取系统

### 3.1 抽取结构

```
消耗金币 → 展示 3 个选项 → 选择 1 个

3 个选项的内容可以是：
  ① 技能（属性加成/特性效果/主动技能）
  ② 副武器（装备到 Slot 2/3/4）

每次 3 个选项中：
  - 至少 1 个是技能
  - 至少 1 个是副武器（如果还有空余栏位）
  - 如果 3 个武器栏位已满，则 3 个都是技能
```

### 3.2 费用递增

```
每次抽取费用 = 100 + 50 × (本阶段已抽取次数)

第 1 次：100 金币
第 2 次：150 金币
第 3 次：200 金币
...
第 8 次：450 金币

每阶段结束时重置（下阶段重新从 100 开始）
```

### 3.3 4 级阶位系统

> 技能和副武器均分为 **4 个阶位（Tier 1~4）**，对应 4 个游戏阶段。越到后期，高阶位出现概率越高。

每局稳定总获取量约 12-18 次抽取。

#### 各阶位解锁条件

| 阶位 | 解锁 | 关键词 |
|------|------|--------|
| **Tier 1** | 阶段 1 即可出现 | 基础属性、简单机制 |
| **Tier 2** | 阶段 1 可少量出现 | 元素附魔、中级机制 |
| **Tier 3** | 阶段 2+ 开始出现 | 复合机制、Build 核心 |
| **Tier 4** | 阶段 3+ 开始出现 | 质变效果、终极武器 |

#### 各阶段抽取概率分布

| 阶段 | T1 | T2 | T3 | T4 |
|------|-----|-----|-----|-----|
| **阶段 1** | 80% | 18% | 2% | 0% |
| **阶段 2** | 40% | 40% | 18% | 2% |
| **阶段 3** | 20% | 35% | 35% | 10% |
| **阶段 4** | 10% | 25% | 40% | 25% |

> 幸运值影响：每 10 点幸运增加 5% 的 T1→T2 或 T2→T3 等的跳阶概率。

### 3.4 排除系统

```
每次抽取后，从 3 个选项中选择 1 个"排除标记"，或选择不排除。

排除规则：
  - 每个技能/副武器可以被排除最多 2 次
  - 排除满 2 次 → 该物品从本局的抽取池中**永久移除**
  - 排除不消耗任何资源
  - 排除了一个选项后，该次抽选中剩下的选项就是你的"战利品"
  - 不能排除自己选择的那个物品

策略价值：
  - 玩家可以逐步"净化"池子，让想要的物品更容易出现
  - 前期排除低阶位垃圾，后期更容易拿到高阶位好东西
  - 用了排除后，相当于每局可以"定制"自己的池子
```

**排除操作的 UI 示意：**
```
┌─────────────────────────────────────┐
│  选择 1 项获取，其余可排除 1 项     │
│                                     │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐
│  │ 攻击力  │  │ 速射炮  │  │ 狗屎运  │
│  │  +5     │  │  ☆1     │  │  +30幸运 │
│  │         │  │         │  │  3次     │
│  │ [选择]  │  │ [选择]  │  │ [选择]  │
│  │ [排除]  │  │ [排除]  │  │ [排除]  │
│  └─────────┘  └─────────┘  └─────────┘
│                                     │
│  排除进度：攻击力 0/2               │
│                                     │
│  [不排除，确认选择]                 │
└─────────────────────────────────────┘
```

### 5.5 副武器升星详解

```
获取同名副武器时自动升星：

☆1 → ☆2：基础属性 +40%
☆2 → ☆3：基础属性 +40% + 解锁"☆3 追加"效果

获取途径：
  - 肉鸽抽取（主要来源）
  - 精英掉落（概率）
  - 阶段 Boss 掉落（必定至少稀有品质，即 ☆2 以上）

品质系统（沿用原设计）：
  普通（白）→ 稀有（蓝）+1 词缀 → 史诗（紫）+2 词缀 → 传说（橙）+3 词缀+特殊效果
  副武器的初始品质由抽取时的"品质判定"决定，幸运影响高品质概率。
```

### 5.6 副武器替换规则

```
玩家当前装备的 3 个副武器（Slot 2/3/4）可以随时替换：

1. 新副武器进入"临时背包"（容量 8 格）
2. 打开背包（可暂停）→ 双击或拖动到目标栏位
3. 替换下的旧武器回到背包或消失（背包满则消失）
4. 被替换的武器保留其星级，重新装备时星级不变
```

### 5.7 排除对副武器的特殊规则

```
玩家可以排除副武器（从抽取池中移除不需要的武器）。
排除 2 次后，该副武器不再出现。

建议策略：
  - 如果 Build 不需要 AoE，可以排除散射炮、迫击炮等
  - 如果走暴击流，可以排除辅助型副武器
  - 排除后池子变小，核心武器更容易出现
```

### 7.2 金币 Boss

```
独立冷却：90 秒
存活时间：20 秒（超时消失，无掉落）

掉落：
  基础：50 + 阶段 × 30 金币
  难度加成：× (1 + 难度 × 0.05)
  幸运加成：每 10 点幸运额外 +5% 金币

策略：
  - 缺金币抽技能时召唤
  - 配合"金币增幅"技能效果更佳
```

### 7.3 击杀 Boss

```
独立冷却：90 秒
存活时间：20 秒

掉落：
  基础：100 + 阶段 × 50 击杀数
  难度加成：× (1 + 难度 × 0.03)

策略：
  - 想买击杀商店大件时召唤
  - 击杀数跨阶段保留
```

### 7.4 经验 Boss

```

掉落：
  基础：相当于击杀 30 + 阶段 × 15 个敌人的经验量
  难度加成：× (1 + 难度 × 0.05)

策略：
  - 卡在 Lv.9/19/29 准备进化专武时召唤
  - 配合"经验增幅"技能
  - 前期召唤加速达到 Lv.10 专武进化
```

## 8. 经济循环总览

### 8.1 资源流动

```
击杀敌人
    │
    ├──→ 经验 ──→ 升级 ──→ 固定属性 + 专武进化（Lv.10/20/30）
    │
    ├──→ 金币 ──→ 肉鸽抽取 ──→ 技能（被动/特性/主动）
    │                                    + 副武器（Slot 2/3/4）
    │              └──→ 手动刷新击杀商店
    │
    └──→ 击杀数 ──→ 击杀商店 ──→ 阶段 Buff（即战力）

召唤 Boss
    │
    ├──→ 金币 Boss ──→ 金币 ──→ 加速抽取
    ├──→ 击杀 Boss ──→ 击杀数 ──→ 加速商店
    └──→ 经验 Boss ──→ 经验 ──→ 加速升级/进化

幸运 ✦
    │
    ├──→ 抽卡品质提升
    ├──→ 副武器初始品质变高
    └──→ 某些技能额外效果
```

### 8.2 各阶段策略建议

```
阶段 1（0-6min）：
  核心目标：Lv.10 专武进化 + 拿到核心 Tier1/Tier2 技能
  抽取策略：抽 2-3 次，优先攻击/攻速 + 基础副武器
  击杀商店：买经验加成加速升级
  Boss：优先召唤经验 Boss（冲 Lv.10）
  排除建议：排除不适合自己玩法的 Tier1 副武器

阶段 2（6-12min）：
  核心目标：Lv.20 专武进化 + Build 初步成型
  抽取策略：抽 3-4 次，找元素附魔和核心 Tier3 技能
  击杀商店：买攻击/攻速 Buff
  Boss：按需召唤
  排除建议：排除不需要的 Tier2 物品

阶段 3（12-18min）：
  核心目标：Lv.30 专武进化 + 高阶武器到手
  抽取策略：抽 3-4 次，找 Tier3/Tier4 质变技能
  击杀商店：买属性灌注/暴击
  Boss：积极召唤，储备资源
  排除建议：进一步净化池子

阶段 4（18-24min）：
  核心目标：冲击高等级，备战最终 Boss
  抽取策略：有金币就抽，补全 Build
  击杀商店：买满有用 Buff
  Boss：全部召唤，最大化资源
```

### 8.3 预期各阶段经济（难度 1，无加成）

| 资源 | 阶段 1 | 阶段 2 | 阶段 3 | 阶段 4 |
|------|--------|--------|--------|--------|

| 击杀数总收入 | ~200 | ~400 | ~600 | ~900 |
| 经验（达成等级） | Lv.10-12 | Lv.20-22 | Lv.30-32 | Lv.35+ |
