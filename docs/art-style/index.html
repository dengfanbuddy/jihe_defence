浅色纸面上的低多边形几何

白模质感的几何图形，一个墨色加一个青绿，铺在近乎无色的纸白底上，靠形状与尺度说话，不靠颜色堆叠。
几何极简 双色制 浅底可读 图纸 / 沙盘感
不是暗底霓虹 不是像素风 不是写实 / 厚涂 不是赛博科技
参考系：Glyphica: Typing Survival 的视觉语法（形象库见 docs/monster-design/、docs/boss-design/）+ 低多边形白模等距渲染（主界面模式插图 textures/game_bg/*.png）。
参考的物：建筑 / 地形沙盘模型、蓝图与工程图纸、留白充足的纸面印刷品。
双强调色是本项目的隐藏口径：青绿 = 系统与操作（按钮 / 进度 / 可点格子 / 范围预告）， 暗红 = 英雄与人（头像格底 / 英雄卡框 / 解锁环）。两色不许互换，也不要用暗红表示报错。

06形状与线条语法

规则口径
双色制一个墨色 + 一个强调色；灰色只承担辅助信息
线宽主结构 2.2~3px，细节 1.2~1.6px，全部圆头；UI 描边 1~2px
圆角三档：4 / 8 / 16（贴图 rect_rd_5 / rd_10 / rd_20，rect_board_* 为只描边的环）
虚线语义虚线 / 淡线 = 范围·预告·未发生；实线 = 已存在的实体
材质无渐变、无阴影、无高光、无贴图纹理；纯色块 + 描边
体量即配置体型倍率同时是碰撞半径倍率（UNIT_VISUALS.scale）：看起来多大 = 被推开多远
剪影优先小尺寸（碰撞直径 ≈50px 量级）下必须能分辨，细节不承担识别任务
状态外挂层数 / 血条 / 词条一律挂在本体外围，不入本体造型

07禁用清单

  • 暗底 + 霓虹发光、赛博科技风
  • 渐变、投影、内 / 外发光、材质纹理、拟物高光
  • 一个界面出现第三种强调色（青绿 / 暗红之外只能是辅助灰或品质色）
  • 用颜色表示"暴击"（颜色通道已被"打谁"占用，暴击用尺度 + 几何标）
  • 把范围圈画成实心或高对比实线（那是"已存在实体"的语法）
  • 用暗红 #A85A5A 表示报错，或用纯红 #FF0000 表示英雄身份
  • 单位识别依赖细节（小尺寸下必须是强剪影）
  • 界面里出现新的青绿 / 墨色（新颜色必须先进规范再进工程）
