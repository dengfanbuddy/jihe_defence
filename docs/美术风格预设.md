## 0. 定调

**一句话**：**浅色纸面上的低多边形几何** —— 白模质感的几何图形，只用一个墨色加一个青绿，铺在近乎无色的纸白底上，靠形状与尺度说话，不靠颜色堆叠。

| 关键词 | 含义 | 反面（别做） |
|---|---|---|
| **几何极简** | 所有形象都是基本几何体（环/盾/方/菱/棱柱）的组合 | 复杂结构、写实细节、机械零件堆叠 |
| **双色制** | 一个墨色 + 一个强调色承载一切，灰色只做辅助信息 | 多彩配色、彩虹渐变、霓虹 |
| **浅底可读** | 底色接近白（冷白/米白），元素靠**描边与明度差**站立 | 暗底发光、大面积深色块 |
| **图纸/沙盘感** | 大量留白、细线、虚线范围圈、等距缩略图 | 满屏特效、粒子、光晕 |

**参考系**：Glyphica: Typing Survival 的视觉语法（`docs/monster-design/`、`docs/boss-design/` 已按它做了形象库）+ 低多边形白模等距渲染（主界面模式插图）。
**参考的物**：建筑/地形沙盘模型、蓝图与工程图纸、留白的纸面印刷品。
**明确不是**：暗底霓虹、像素风、写实、卡通厚涂、赛博科技。

**风格研究（不改本文口径）**：《尼尔：机械纪元》UI 的拆解与借鉴结论 —— 含"**母题 = 工程图纸**"六件套方案与三条现役颜色纪律漏洞 —— 见 `docs/art-style/nier-ui-reference.md`；六组「现在 / 借用后」可视化对照板见 `docs/art-style/nier-borrow-board.html`。采纳与否在那边 §8 待拍板，**拍板前不动本文任何口径**。

### 1.8 档位色 · 成就 `tier`（3 档）

| Token | 值 | 用途 | 现状出处 | 状态 |
|---|---|---|---|---|
| `c-tier-bronze` | `#C98B5E` | 成就**铜**档 | `game/common/AchievementTierColor.ts` | ✅ |
| `c-tier-silver` | `#B9C4CC` | 成就**银**档 | 同上 | ✅ |
| `c-tier-gold` | `#F2C14E` | 成就**金**档 | 同上 | ✅ |

> **与品质色同族**：它回答的是「这条成就滚到第几档」，不回答「能不能点」（那是 `c-accent-action`）也不回答「属于谁」（那是 `c-identity`）。
> **只许两点式使用**：卡面左缘那条刻度条（`tier_bar`）+ 档位名文字。**不许铺成卡面底色** —— 浅底上会与正文的深色字抢对比度（金档 `#F2C14E` 压白底只有 1.5:1），
> 而且铜/银/金是本卡唯一的暖色，铺面积就变成「一个界面里的第三种强调色」（违反 §10）。档位差主要靠**形状与位置**（刻度条）而不是靠色相铺张 —— 同 §9-4 的原则。
> 两个容易混的近邻：`c-tier-silver #B9C4CC` ≠ `c-disabled-pill #B9C1C1`（差 3 个灰阶，一个是银档、一个是"不可点"）；`c-tier-gold #F2C14E` ≠ `c-gold #D38C1E`（前者是金档徽记，后者是"金币"这个资源）。

## 2. 调性裁决：三份来源的主张 vs 现行基线

| 来源 | 主张 | 裁决 |
|---|---|---|
| `docs/prd/肉鸽塔防_游戏设计定案.md` §18「暗色背景（深灰/黑色）」 | 暗底 + 冷色主调 | ❌ **已废弃**：那是立项期的 Glyphica 直译。实机为**浅底纸面**，PRD 该节已加指向本文的说明 |

## 3. 形状与线条语法

| 规则 | 口径 | 落地 |
|---|---|---|
| 双色制 | 一个墨色 + 一个强调色；灰色只承担辅助信息 | 见 §1 |
| 线宽 | 主结构 **2.2~3px**，细节 **1.2~1.6px**，全部**圆头**；UI 描边 1~2px | 形象库 SVG 与 UI 贴图一致 |
| 圆角 | 三档：**小 4 / 中 8 / 大 16**（视觉半径） | 贴图 `rect_rd_5`(小) / `rect_rd_10`·`rect_board_rd_10`(中) / `rect_rd_20`·`rect_board_rd_20`(大)；`rect_*_white` 为纯白版、`rect_board_*` 为**只描边不填充**的环 |
| 虚线 vs 实线 | **虚线/淡线 = 范围·预告·未发生**；**实线 = 已存在的实体** | 战场范围圈必须是淡线（`c-range-line`），不能画成实心环 |
| 材质 | **无渐变、无阴影、无高光、无贴图纹理**；纯色块 + 描边 | 关卡缩略图（`textures/game_bg/*.png`）为低多边形白模，只有青灰明度阶（主色族 `#608080`/`#80A0A0`/`#A0C0C0`/`#C0C0C0`） |
| 体量即配置 | 单位体型倍率同时是碰撞半径倍率（`UNIT_VISUALS.scale`），"看起来多大"就是"被推开多远" | 改体型只动 `EntityVisualConfig.ts` |
| 剪影优先 | 单位在小尺寸（碰撞半径 26 ≈ 直径 50px 量级）下必须能分辨，细节不许承担识别任务 | 参考 `ours.html` 的「体量对照」页 |
| 状态外挂 | 层数/血条/词条等状态信息一律挂在**本体外围**，不入本体造型 | 形象库既定规则 |

## 4. 排版

- **字体**：工程全量 `Arial`（`Label._fontFamily` 实测：菜单 80 处、战斗 49 处），中文靠系统字体回退。
  → **建议**：正式版锁一套"数字/拉丁 = Arial（或等宽数字），中文 = 系统黑体"的方案，并明确 3 个数字字体用途（大数值、倒计时、飘字）。飘字是**手写几何字形**（`GeometricDigits.ts`，零字体资产），不受字体方案影响。
- **字号阶梯**（实测在用值，收敛为 5 档）：

| 档 | 字号 | 用途 | 实测 |
|---|---|---|---|
| Display | **40** | 等级大数字、页面主标题 | 菜单 `lv`/`name` 40；战斗结算 `title` 40 |
| H1 | **24** | 强调数值 | 战斗 `value` 24 |
| H2 | **20** | 卡片标题、正文主体、数值 | 两界面最常用（菜单 4+4+11 处） |
| Body | **16** | 说明、次级数值、按钮文字 | 两界面 |
| Caption | **14** / **12** | 辅助说明、单位后缀 | 菜单 `name`/`value` 14；战斗 `desc` 12 |

- **描边**：`#14181B`，宽度 = 字号 × `0.12`（飘字）；浅底上的白字**必须**描边，白底白字不可读。
- **数字**：数值一律 `<当前>/<上限>` 形式（`300/300`），用斜杠不用箭头。
- **字重**：只区分"常规 / 加粗"两档，不用多字重。

## 5. 战斗场景规范（"图纸沙盘"）

| 元素 | 规范 | 出处 |
|---|---|---|
| 战场底 | 纯色 `c-canvas-battle` `#EBF4FB` 全屏铺满，**无纹理、无网格、无暗角** | `Scene_Game_Stage.prefab` 全屏 Sprite |
| 范围圈 | 1px 淡青灰 `#C0CCD1`（更淡时可用 `#EBF4FB` 上叠青绿 25% alpha ≈ `#CADDE3`），**只描边不填充**，不用实心圆 | `GraphCircle` + 预制件 lineColor |
| 英雄本体 | **青绿空心圆环**（`accent` 族），体量克制，靠"环"而不是"块"表达"我=中心" | 图1 中心标记实测 `#6AAAB0` |
| 敌人本体 | **灰调墨线徽记**（白模 + 墨线 + 暖色排线），浅底上以灰阶区分，不靠彩色 | 图1 左侧敌人实测 `#6A696B`/`#000000` |

## 7. 给 AI 出图 / 参考板用的风格串

出图（概念图、缩略图、宣传图）时，把下面这段作为**风格前缀**接在内容描述前，避免出成写实或暗底霓虹。

> 极简几何风格，低多边形白模质感，浅色纸面背景（冷白 #EBF4FB / 米白 #EFEEED），只用一个墨灰（#445054~#6A696B）加一个青绿（#67999A / #70ACB3），大留白，细线描边，无渐变无阴影无高光，等距视角，干净的 UI 布局，克制的几何装饰。

> minimal geometric art style, low-poly untextured clay-model look, paper-white background (cool white #EBF4FB / warm off-white #EFEEED), duotone palette: one ink grey (#445054–#6A696B) + one teal accent (#67999A / #70ACB3), generous negative space, thin clean outlines, flat shading only — no gradients, no drop shadows, no specular highlights, isometric composition, tidy minimal UI layout, restrained geometric ornaments, muted desaturated look.

**负向词（Negative）**
> dark background, neon glow, cyberpunk, photorealistic, painterly, heavy textures, colorful gradients, busy particles, lens flare, drop shadow, bevelled edges, high saturation rainbow palette.

## 9. 待收敛差异（**本文最有行动价值的一节**）

按优先级排列；每条含「现象 → 建议动作 → 影响面」。

1. **青绿四胞胎**：`#67999A`（品牌/代码）、`#70ACB3`（最常用填充）、`#6FA9A7`（选中环，烘焙在贴图里）、`#689B9B`（次按钮）。
   → 建议定为两级：`accent-600 #67999A`（前景/按钮/描边）+ `accent-400 #70ACB3`（大面积填充），`#689B9B` 合并进 600，`#6FA9A7` 保留为「选中环」专用色并**只存在于贴图**（不写进代码）。
   → 影响：`Top_ChangeScene.ts`（无需改，已是 600）、两处预制件若干节点。
2. **墨色两调**：菜单用冷板岩（`#445054`/`#465259`/`#56636A`），战斗 HUD 用中性灰 `#6A696B`。
   → 建议统一为一条 ramp：`900 #445054 / 800 #465259 / 700 #56636A / 600 #6A696B / 400 #999999 / 200 #D8D8D8`，并规定「栏底用 800/700、标题用 900、正文与图标用 600、次要文字用 400」；`#5D5C5B`（属性图标）并入 600。
   → 影响：`View_Game_Stage` 12 处 + `HeroSelectPanel`/`ShopRelicsPanel` 的硬编码 `Color("6A696B")`。
3. **无"危险/失败"色定义**：代码里金币不足直接 `new Color(255,0,0)` 纯红。
   → 建议定义 `c-danger = #C0392B`（低饱和、与 `#A85A5A` 同族不同明度），并规定 `c-danger` 只用于**文字与细线**；`#A85A5A` 只用于**英雄身份**，两者不许互换。
   → 影响：2 处 TS + 未来所有报错/不可用态。
4. **单位配色与浅底冲突**：`#9B59B6`（精英）、`#E74C3C`（经济 Boss）、`#3B1C32`（Boss）、受击 `#00FFFF`/`#FFA500` 属于**早期高饱和口径**，与实机截图的灰调墨线徽记不是一套；且 `#6B8E9B` 在 `#EBF4FB` 上对比度偏低、`#3B1C32` 又过重。
   → 建议：① 主色相留在青灰族（普通 `#6B8E9B` 可保留或加深至 `#5A7C88`），② 档位差**主要靠体型与徽记附件**（外环/王冠/基座）而不是靠换色相，③ 高饱和色只保留**一个**给"经济 Boss"（金币橙）以示"打它有收益"，④ 受击色统一为「本体色向白提亮 60%」，仅在英雄受击保留 `#FF4C4C`。
   → 影响：`EntityVisualConfig.ts`（单点）+ 实机观感，需一次美术评审后一次性落。
5. **品质色两套**：工程 UI = 白/蓝/**紫**/红（`#DDDDDD`/`#5096FF`/`#CF68FF`/`#FF6464`），设计稿与配表（`rarity: common/rare/epic/legendary`）= 白/蓝/**黄**/红。
   → 建议**以工程现值为准**（浅底上紫色比黄色更易读、色相跨度更均匀），把 `docs/hero-design/` 文字口径同步为紫；若坚持黄色，则需替换 6 处预制件颜色。
   → 影响：`docs/hero-design/README.md`（或 6 处预制件）+ 未来所有品质相关 UI。
6. **菜单卡片插图风格已成型但未入库为规范**：`game_bg/*.png` 是"等距低多边形白模 + 青灰明度阶"，出图口径与 §7 一致——但只有 3 张，且**没有对应的出图规范文档**。
   → 建议补一节「缩略图出图规范」（视角：等距 30°；无贴图；只允许 §7 色板；留白 ≥ 画面 30%；底部对齐卡片下沿），并规定新关卡必须同源出图。
7. **`GraphCircle.ts` 默认线色是荧光绿 `(0,255,0,100)`**（骨架屏遗留）。新建节点若忘记改 lineColor 就会出现一道荧光绿圈，与风格严重冲突。
   → 建议把默认值改成 `#C0CCD1`（alpha 100→255 或 0.4 透明度按需）。

## 10. 禁用清单（Do Not）

- ❌ 暗底 + 霓虹发光、赛博科技风
- ❌ 渐变、投影、内发光、外发光、材质纹理、拟物高光
- ❌ 一个界面里出现第三种强调色（青绿 / 暗红之外的颜色必须是"辅助灰"或"品质色"）
- ❌ 用颜色表示"暴击"（颜色通道已被"打谁"占用；暴击用**尺度 + 几何标**）
- ❌ 把范围圈画成实心或高对比实线（那是"已存在的实体"的语法）
- ❌ 用暗红 `#A85A5A` 表示报错，用纯红 `#FF0000` 表示英雄身份
- ❌ 单位识别依赖细节（小尺寸下必须是强剪影）
- ❌ 界面里出现新的青绿/墨色（新颜色必须先进本文 §1 再进工程）
