数值：奖励公式、每类敌人基数、缩放常量、局内/局外两套经验体系。

奖励公式

跨阶段靠难度系数跳变；阶段内靠时间通胀缓涨。二者相乘。金币 Boss / 经验 Boss 在基础值上再乘专属倍率。
金币 Boss 特例：gold *= rewardBossGoldBonus；经验 Boss 特例：exp *= rewardBossExpBonus。只放大对应资源，另一项保持低值。

经验升级曲线（既有）

两套经验（关键）：局内经验 → 局内英雄升级加属性（局终清零）；局外经验 → 对局结束按配置一次性发放，与局内击杀经验完全无关。击杀奖励只产局内经验；局外经验只由结算配置决定。

局内经验 / 等级（击杀产出）

击杀敌人的 expReward 修正后作为局内经验，填满当前等级后升级，并按 heroes.json 的 growthValues 给英雄加属性。

字段公式 / 值说明
局内经验公式expToNext = battleExpFormulaBase × ratio^(level-1)60 / 1.18
等级上限battleLevelMax30 级封顶
升级加属性attrs.addBase(attrId, growthValues)按 heroes.json 每级成长加属性
当前血补满hero.hp = getMaxHp()升级后满血
注意：growthValues 用 float 语义（critRate 0.005 = 0.5%），而 addBase 把入参当配置 int 处理。代码里已先转成配置 int（×scale）再 add，避免数值错 100 倍。

局外经验 / 等级（结算产出）

对局结束 finish() 时按配置一次性发，与击杀数/局内等级无关。失败按 30% 参与度补偿。

字段公式 / 值说明
玩家经验clearRewardPlayerExpBase × ratio胜利 ×1.0 / 失败 ×0.3，50 基础
英雄经验clearRewardHeroExpBase × ratio发到 HeroData 对应英雄，80 基础
升级公式heroExpFormulaBase × ratio^(level-1)100 / 1.12（英雄）；玩家用 100 / 1.15
备注：局外英雄经验目前取第一个已解锁英雄兜底发放（HeroData 只存 id/level/exp，不存名字，无法按英雄名精确匹配）。若需按出战英雄发，需在 selectHero 时记录稳定 heroId。
