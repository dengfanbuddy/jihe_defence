奖励公式

定案变更（见「结算」页·第三轮 7）：金币不再吃任何缩放。金币直接取 units.json 的 goldReward；阶段系数与时间通胀只作用于局内经验。目的：让"一局金币花光能抽多少次"变成可精确设计的定值（而不再 base × 1.44 反算）。
金币 = 定值（便于反推抽卡预算：一局 6,900 金 = 正好 231 抽 = 遗物池 293 的 78.8%）；局内经验仍跨阶段跳变、阶段内缓涨。金币 Boss / 经验 Boss 的专属倍率建议删除（见下）。
代码要拆函数：Scene_Game_Stage.currentRewardScale() 现在同时给金币和经验用，需要拆成两份（金币直给、经验保留缩放）。
两个 ×10 倍率建议删掉：gold *= rewardBossGoldBonus / exp *= rewardBossExpBonus（都 = 10）会让金币 Boss 实得 250×10 = 2,500、经验 Boss 实得 200×10 = 2,000 局内经验 —— "base = 到账值"就不成立了，数值藏在了别的表里。建议直接把 1,700 / 2,000 写进 units.json，删掉这两个常量。

经验升级曲线（既有）

两套经验（关键）：局内经验 → 局内英雄升级加属性（局终清零）；局外经验 → 对局结束按配置一次性发放，与局内击杀经验完全无关。击杀奖励只产局内经验；局外经验只由结算配置决定。

局内经验 / 等级（击杀产出）

击杀敌人的 expReward 修正后作为局内经验，填满当前等级后升级，并按 heroes.json 的 growthValues 给英雄加属性。
