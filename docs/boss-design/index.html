51 只怪物 · Dota2 基因 × 阶段与难度

以 dota2 的怪物/野怪/首领为灵感，改造成本作的分阶段推进体系： 4 个阶段（每阶段 3 小怪 + 3 精英 + 1 守关Boss）、3 个全局特殊Boss（金币 / 击杀 / 防守，均不主动攻击）、 以及最终阶段后的 20 个最终Boss。

小怪与精英攻击频率都很低（攻频 0.6~1.0 左右），但攻击力与血量更高；Boss 带小技能，最终Boss 带 1~2 个主动技能。 全部形象为参数化生成的原创 Glyph 徽记，可导出 SVG / PNG。

02

阶段推进

4 个阶段，难度倍率逐段提高（阶段1 = 1.0 → 阶段4 = 3.6）。每阶段 3 种小怪 + 3 种精英 + 1 只守关Boss。 小怪/精英攻频低、血攻高；守关Boss 带小技能。

03

全局特殊Boss

3 只不会主动攻击的任务 / 收益首领：金币Boss（击杀爆金币）、击杀Boss（限时击杀拿经验）、防守Boss（攻防核心，需拆解）。 三者把奖励或任务目标直接画在剪影上。

04

最终Boss · 难度循环

本作设 100 级难度，每 5 级一个类型的最终Boss（难度1-5→第1只 … 难度96-100→第20只）， 之后循环这 20 只，仅按 difficultyMultiplier 提高属性。每只最终Boss 都带 1~2 个主动技能。
