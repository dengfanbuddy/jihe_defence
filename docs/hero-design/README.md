# 英雄设计库 · 30 英雄 / 293 道具 / 30 额外技能 / 20 击杀 Buff

参照 Dota 2 英雄与装备的特质，为本作《集合防御》做的整体卡池设计。双击 `index.html` 打开。

## 内容

| 模块 | 数量 | 说明 |
|---|---|---|
| 英雄 | 30 | **被动 / 普攻为固定效果（无升级）**；**仅技能**随英雄等级 Lv.1/10/20/30 升级 |
| 肉鸽商店道具 | 293 | 对应 **dota2 全部装备**，4 品质（白/蓝/黄/红），**无合成概念**，带官方图标 |
| 额外技能库 | 30 | 3 个额外技能槽可抽取，同名升 1 级；品质 白/蓝/黄/红，**高品质概率随英雄等级提升** |
| 击杀商店 Buff | 20 | 击杀点购买，可重复、价格递增，均为百分比加成 |

## 英雄结构（本次变更）

- `passive`：`{ name, desc }` —— 静态，1 条
- `attack`：`{ name, desc }` —— 静态，1 条
- `skill`：`{ name, lv1, lv10, lv20, lv30 }` —— 唯一成长点，4 档升级

## 道具（本次变更）

- 对应 dota2 全部 293 件装备，字段：`code/name/en/cost/quality/img/attr/effect/lore/suggest/tags`
- `quality`：白 / 蓝 / 黄 / 红（依 dota2 装备品质与价值换算，无合成树）
- `img`：dota2 官方装备图标 URL
- `suggest`：本作百分比换算参考；`attr`：原 dota2 属性；`effect`：原技能效果

## 技能品质抽取（随等级提升）

| 英雄等级 | 白 | 蓝 | 黄 | 红 |
|---|---|---|---|---|
| Lv.1-9 | 55% | 30% | 12% | 3% |
| Lv.10-19 | 40% | 32% | 20% | 8% |
| Lv.20-29 | 28% | 34% | 24% | 14% |
| Lv.30 | 20% | 30% | 26% | 24% |

## 核心数值口径

- 8 属性：攻击力 / 生命值 / 攻击范围(m) / 护甲 / 攻击速度 / 暴击率 / 闪避 / 生命恢复
- 上限：射程 15m、攻速 3.0、暴击 60%、闪避 40%、护甲减伤 70%（护甲/(护甲+100)）
- Lv.1 基础属性严格取自「倾向映射表」，成长侧重五选一，每英雄「两高两低」
- 局内 Buff / 道具 / 击杀 Buff 一律百分比、同类加法叠加，只对英雄基础属性乘算

