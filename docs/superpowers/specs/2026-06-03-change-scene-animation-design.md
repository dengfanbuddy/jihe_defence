# Top_ChangeScene: 形态融合场景切换动画

## 概述
使用 Cocos Creator Graphics API 实现的场景加载过渡动画。组件监听全局事件 `SCENE_LOAD_PROGRESS` 接收加载进度，全屏显示几何形态变换动画。

## 配色
- 主色: #67999A (青绿) — 图形、进度环、粒子
- 辅色: #EFEEED (米白) — 百分比文字、装饰光效
- 背景: rgba(0,0,0,0.7) 半透明遮罩

## 结构
- 全屏覆盖 (750×1334)
- 动画中心在屏幕中央 (375, 667)
- 外圈进度环直径 ~400px

## 组件构成
- `Graphics` × 1: 绘制所有图形（形态、进度环、粒子、闪光）
- `Label` × 1: 显示百分比数字

## 阶段一：循环加载动画

### 形态变换序列
1.5s 循环：三角形 → 正方形 → 圆形 → 六边形 → ...

每个形态用 Graphics 绘制多边形顶点：
- 三角形: 3顶点等分圆
- 正方形: 4顶点等分圆
- 圆形: 多段线近似（或直接 circle）
- 六边形: 6顶点等分圆

形态过渡使用 lerp 插值，0.5s 内完成顶点位置变化。

### 整体旋转
每 4s 旋转 360°，持续旋转。

### 外圈进度环
- 用 Graphics.arc 从 -90° 开始顺时针绘制
- 弧度 = progress × 2π
- 宽度 4px，线帽圆角

### 粒子效果
- 6~8 颗小圆点粒子
- 绕中心沿圆形轨道运行
- 透明度 + 大小随轨道位置变化

## 阶段二：完成动画
1. progress = 1.0 触发
2. 图形膨胀到 1.5x (0.3s)
3. 碎裂成 12~16 个碎片粒子飞散 (0.5s)
4. 全屏白色闪光渐隐 (0.3s)
5. 组件自销毁

## 事件接口
- 监听: `GlobalEventMgr.ins.addNotice("SCENE_LOAD_PROGRESS", this, this.onProgress)`
- 事件参数: `progress: number` (0~1)
