最终设计方案（精简版）

架构

Top_ChangeScene Component
├── start() → 监听 GlobalEventMgr.ins "SCENE_LOAD_PROGRESS" 事件
├── onProgress(progress: number) → 更新动画 + 百分比
│   ├── progress < 1.0 → 循环形态变换 + 进度环 + 粒子
│   └── progress = 1.0 → 完成转场动画
└── update(dt) → 每帧更新动画状态

动画细节

① 中心形态变换（循环）

每 1.5s 切换一次形态：
三角形 → 方形 → 圆形 → 六边形 → 循环

  • 形态间用 Graphics.moveTo/lineTo/circle 插值过渡（0.5s）
  • 整体持续缓慢旋转（每 4s 转 360°）
  • 边缘发光效果：半透明 #67999A 的叠加描边

② 外圈进度环

使用 Graphics.arc 绘制弧形进度
角度范围：从 -90°（12点方向）顺时针到 -90° + progress × 360°

③ 百分比文字

用 Label 组件（非 Graphics，文字更清晰）显示 "72%"
辅色 #EFEEED，大号加粗

④ 粒子效果

6~8 颗小圆点粒子沿圆形轨道绕中心旋转
透明度 + 大小随位置变化（正面亮背面暗）

⑤ 完成动画

  • progress = 1.0 时：图形膨胀 → 碎裂粒子 → 全屏白色闪光
  • 碎粒飞散，透明度渐减到 0
  • 闪光渐隐后，组件 self.destroy()
