# 数值方法论速查（本技能使用）

> 出处汇总见 `docs/数值设计调研报告_肉鸽塔防.md`（完整 14 张表与来源链接）。此处为执行速查。

## 0. 三模式与局外成长（先定基准，再配数）

2026 确认的模式定义。任何配置产出前先问清"给哪个模式、什么难度/档位基准"。

| 模式 | 玩法 | 数值目标 | 局内等级 |
|---|---|---|---|
| **难度模式** | 难度 1~100（可续扩），每 5 难度换一个不同关底 Boss；前 3 难度偏易、首日可勉强通过 | 每难度 ≈ 关卡；难度推进 ≈ 局外成长推进（**3~4 天/难度**匀速） | 无上限 |
| **无尽模式** | 选定难度基准后无阶段限制刷到死 | 怪强度随时间/波次超线性增长，普通玩家 15~40min 自然死亡 | 无上限 |
| **Boss 模式** | 独立 Boss 池（**与难度关底两套**），挑战掉碎片 → 集齐合成 → 永久收集属性 | Boss HP = 该档满配 DPS × 10~30s；碎片经济 + 收集属性入局外池 | 无上限 |

局外成长层（都注册进 `OuterAttributeCalculator`，按 feature 分组）：英雄独立成长 / 公共装备图鉴收集 / 成就 / Boss 收集 / 广告加速 / 未来新增。
**铁律：全部永久层合计 ≤ +50% 乘区**；新系统在总预算内切份额，不无限叠。

难度曲线（难度模式 1~100+）：`HP(N)≈基准×(1+dHp)^(N-1)`（dHp 0.08~0.15）、`伤害(N)≈基准×(1+dAtk)^(N-1)`（dAtk<dHp，0.06~0.10）；每 5 难度换关底 Boss；dHp/dAtk 要与"每天局外净成长 ×3~4 天"匹配（如每天净成长 2%，3~4 天≈+6~8%，dHp 取 ~0.08 才不会追不上/太简单）。

无尽曲线：怪 HP/伤害 每 60~120s ×1.05~1.1（或按波次 ×1.03~1.08），收益设 cap 防刷爆。

## 1. 黄金锚点表

| 锚点 | 取值 | 用途 |

## 2. 五步配数法

```
① 定手感 TTK：该英雄打普通怪几秒杀？该阶段小怪摸英雄几下死？
② 定锚换算：DPS = 敌HP / TTK；英雄HP ≈ 被命中次数 × 单怪伤害 × 容错
③ 拆乘区：把输出拆为 攻击力 / 攻速 / 暴击(率:伤 = 1:2) / 增伤
④ 验生存：EHP = HP/(1-减伤)；闪避折算减伤(20%闪 ≈ 20%减伤)
⑤ 封口：配消耗与封顶（暴率≤60%、闪避≤40%、攻速≤3、总膨胀≤2倍）
```

## 3. 输出与技能预算常用公式

```
单发普攻DPS = 攻击力 / (attack_interval / atkSpeed)
暴击期望乘数 = 1 + 暴率 × (暴伤-1)
技能单发预算 ≈ 普攻单发 × 1.5~3（靠冷却摊平到秒伤）
DoT/触发类定价：面额 = 等效秒伤 × 覆盖率（20%触发 → ×0.2~0.4）
```

## 4. 经济预算

- 单局金币总预算 = 目标抽取次数 × 单次均价（费用递增 100+50×n）。
- 反推普通怪单价：金币 Boss/精英/Boss 各占比例的加权和。
- 局外「税」消耗吞 85~90% 产出防通胀；局内肉鸽可花 80~90%。
- 无尽模式局内收益设 cap（复用 `rewardTimeCap` 思路），防单局刷爆局外；Boss 模式走碎片+固定奖励。

## 5. 怪物比例锚

| 类型 | HP 比例 | 伤害比例 | 奖励 |
|---|---|---|---|
| 普通 | 基准 | 低（3~8 下致死英雄） | 1× |
| 精英 | 5~10× | ≈2× | 金币 5~10×、经验 3~5× |
| 阶段/关底 Boss | 满配 DPS × 10~30s | 高 | 30~100× |
| 经济/经验 Boss | 偏肉 | 中 | 专项目标资源 |

## 6. 波次/难度增长（按模式，见 §0）

- 难度模式（关卡制）：难度 N HP ≈ 基准×(1+dHp)^(N-1)、伤害 ≈×(1+dAtk)^(N-1)，dHp 0.08~0.15 > dAtk 0.06~0.10；局内若分阶段可套「阶段系数 ≈ 1.5^(阶段-1)」。
- 无尽模式：怪强度随时间/波次超线性增长（每 60~120s ×1.05~1.1），目标是玩家 15~40min 自然死亡。
- 奖励随难度同步：收益增速 ≥ HP 增速的 60~70%，缺口由局外成长补足并写进难度表。
