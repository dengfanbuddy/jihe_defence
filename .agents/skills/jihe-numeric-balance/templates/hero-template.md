# 英雄数值设计模板（输出设计表用）

> 填写时每个值附【依据】；最后转 JSON 时按 conventions §2 两条例律换算。

## A. 英雄设定（用户输入抄录）

| 项 | 内容 |
|---|---|
| 名称 / 定位 | |
| 目标模式与基准 | （难度 N / 无尽基准难度 / Boss 档位，见 quick-method §0） |
| 玩法节奏 | （近战普攻 / 远程弹道 / 技能爆发 / 光环……） |
| 特色机制 | |
| 局外成长预算 | （该英雄是否吃 英雄独立成长/公共装备/成就/Boss收集，各给多少） |

## B. 基础属性设计表

| 属性(名) | 设计值(运行语义) | 配置值(base_attributes) | 依据 |
|---|---|---|---|
| 最大生命(1) | | | HP ≈ 10×DPS×安全系数 |
| 最大魔法(2) | | | 消耗型英雄才需要 |
| 攻击力(3) | | | 与 attack_interval 合算 DPS |
| 攻击速度(4) | | ×100 后写 | |
| 移动速度(5) | | | 英雄守点可不配 |
| 护甲(6) | | | 按减伤公式反推 |
| 魔法抗性(7) | | ×100 | 默认 25 |
| 闪避(8) | | ×100 | |
| 生命恢复(9) | | | |
| 魔法恢复(10) | | | |
| 伤害输出倍率(11) | | ×100 | |
| 暴击率(14) | | ×100 | ≤60 |
| 暴击倍率(15) | | ×100 | 默认 150 |
| 攻击距离(16) | | | 像素口径 |
| 普攻间隔(attack_interval) | 秒 | | 直接字段 |

**校验**：单发普攻DPS = 攻击 / (间隔/攻速)；TTK = 目标怪HP / DPS（应 0.5~3s）。
