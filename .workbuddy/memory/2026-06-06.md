# 2026-06-06

## 数据架构设计

在 `assets/scripts/game/data/` 下完成了完整的数据架构设计和实现：

### 文件结构
```
data/
├── StorageUtil.ts       # localStorage 底层封装（namespace、异常安全）
├── DataModule.ts        # 数据模块基类（reactive + watch 自动存）
├── DataCenter.ts        # 数据中心单例（统一管理所有模块）
├── index.ts             # 统一导出入口
├── funcs/
│   ├── PlayerInfo.ts    # 玩家基础信息（等级、经验、签到、统计）
│   ├── HeroData.ts      # 英雄数据（解锁、升级、阵容）
│   └── ItemData.ts      # 道具/资源（货币、背包道具、装备）
```

### 核心设计
- **DataModule<T>** 利用平台已有的 `reactive()` + `watch(deep:true)` 实现"修改即自动保存"
- 100ms debounce 批量写 localStorage，避免频繁 IO
- 加载时深度合并（schema 演进兼容：新增字段自动用默认值填充）
- `serialize()` / `deserialize()` 支持存档导入导出
- `toRaw()` 剥离 reactive Proxy 后序列化，JSON 干净无 Proxy 痕迹
- DataCenter 提供 `saveAll()` / `resetAll()` / `exportAll()` / `importAll()` 统一接口
